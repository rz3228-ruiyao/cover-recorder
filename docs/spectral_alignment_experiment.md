# 频谱特征对齐实验

日期：2026-09-18。用户提出：外录与内录包含对应的频谱结构，STFT 特征能否改善响度包络对单一节奏的匹配？本轮完成离线对比，未修改应用算法、界面或自动导出策略，未重新录制或改写私人素材。

后续状态：用户随后授权接入，现已完成。本文保留接入前实验及其门限，不代表当前应用策略；当前算法、回归和自动导出门槛见 [接入记录](spectral_alignment_integration.md)。实验脚本的 `production_rms` 标签固定指向旧的 `estimate_offset_robust()`，用于保持历史基线，不是更新后应用使用的混合流程。

## 结论

实验支持该假设的具体版本：**等间隔、等响度、音高随时间变化时，保留频带信息可以消除整体响度包络中的大量拍间歧义。** 两种频谱特征在第二批 100 组有唯一对应位置的生成输入上均在 40 ms 容差内找到偏移，其中包含 20 组非等间隔对照。

目前更值得继续验证的是 **分频带对数能量（logbands）**。多频带起音特征（bandflux）在生成输入中表现良好，但在两组真实录音上的相关分数明显偏低；这不证明该特征一般更差，只说明当前参数与共享门限下没有比 logbands 更有说服力的实录结果。

两组真实素材的已确认偏移仍被复现到 0–10 ms 差异范围。对照算法在这两组中也找到正确候选，因此不能宣称新算法提高了这两组实录的对齐精度。

推荐后续将 logbands 作为一个候选来源，配合包络和分段一致性，而非马上替换生产算法。新的可信度门限尚未校准，不将本轮 `accepted` 直接用于自动导出。

## 方法与公平比较

比较三种特征，放入同一个时间匹配器：

| 标识 | 特征 |
| --- | --- |
| rms | 复用当前程序的 40 ms RMS 包络、10 ms 步长、对数压缩、去趋势与标准化 |
| logbands | 64 ms Hann 窗 / 10 ms 步长 STFT；80–6500 Hz 的 48 个对数分布三角频带；聚合功率、对数压缩、逐频带去均值及标准化 |
| bandflux | 对同一频带对数能量做时间差分，仅保留正变化，再逐频带去均值及标准化 |

三种方法均将输入统一到 16 kHz。频谱特征的标准差下限为最大频带标准差的 15%，限制对低变化频带的放大；仍未实现完善的噪声检测或活动频带选择。

共享匹配器对各频带沿时间轴做 FFT 互相关并求和，按每个候选的实际重叠区能量归一化。候选必须覆盖至少 5 秒，且不少于较短序列的 50%。次峰排除范围为主峰 ±100 ms，以便能检查常见的半秒拍间歧义。

首次运行前固定实验接受门限：相关分数 ≥ 0.35，主峰 / 次峰 ≥ 1.25。两批生成输入及真实输入之间没有调整这些参数。它们是探索性工程门限，不是统计概率，也未在独立负样本库上完成校准。

另直接调用当前应用的 `estimate_offset_robust()`，标为 `production_rms`。它包含分段一致性判断，使用完整序列能量归一化、主峰 ±1 秒次峰排除区及原有 high 判定。其门限与共享匹配器不同，因此不能把接受数量差异全部归因于特征。这个对照也统一到了 16 kHz；应用通常分析 48 kHz 输入，不将本次表格宣称为未经任何预处理变化的运行基准。

## 数据设计

初试采用种子 100–109，共 70 对输入；复核采用此前未看的种子 1000–1019，共 140 对。每个种子覆盖 7 类场景，生成同一份 60 秒源素材的两个独立连续截段，长度分别为 26 秒和 22 秒。偏移包含正负方向：+370、+1230、−1770、+2830、−2710 ms。

不把一整段声音简单地补一段静音后当作唯一实验：两个输入都从连续演奏中间截取，避免共同起音和静音边缘直接泄露答案。

1. **irregular_clean**：不同音高、不规则起音的干净对照。
2. **regular_pitch_clean**：每半秒起音，固定包络、每音 RMS 相同，音高序列变化。这是针对用户假设设计的包络弱项，不代表日常录音的自然分布。
3. **regular_pitch_room**：在上一场景参考音上加入 180–2800 Hz 带通、17 / 41 / 73 ms 回声和约 18 dB 信噪比噪声。
4. **regular_pitch_mix**：两路混入不同比例的同一段生成伴奏，参考音再经过房间模拟。
5. **regular_pitch_distorted**：外部音频经 tanh 失真，参考声经滤波、回声和约 12 dB 信噪比噪声。
6. **repeated_note**：同音按固定周期重复。应报告歧义；不把任意一个等价周期位置当唯一真值。
7. **unrelated_same_rhythm**：相同节奏和音色生成机制，但两路旋律序列不同，应拒绝匹配。

滤波和短回声是可控模拟，不能代替真实房间、真实设备和复杂效果器测试。初试和复核使用同一生成器，因此第二批属于不同随机样例复核，不是外部真实数据集。

## 第二批结果

下表为种子 1000–1019；每格为误差不超过 40 ms 的数量 / 20。原始偏移、分数和峰比均保存在本机报告。

| 场景 | 包络，共享匹配器 | 分频带频谱 | 多频带起音 | 当前 robust 包络逻辑 |
| --- | ---: | ---: | ---: | ---: |
| 非等间隔干净演奏 | 20/20 | 20/20 | 20/20 | 20/20 |
| 等间隔、等响度、不同音高 | 0/20 | 20/20 | 20/20 | 0/20 |
| 上述演奏 + 滤波、回声、噪声 | 0/20 | 20/20 | 20/20 | 1/20 |
| 两路伴奏比例不同 | 20/20 | 20/20 | 20/20 | 19/20 |
| 失真及更强噪声 | 0/20 | 20/20 | 20/20 | 1/20 |
| 合计 | 40/100 | 100/100 | 100/100 | 41/100 |

不能将“100/100”写为面向任意录音的 100% 准确率。这里的独特音高序列、等能量包络和规则起音是人为设计，主要验证频谱信息能否解决特定歧义。100 组也不是 100 个互相独立的真实演奏，多个场景复用了同一种子的旋律。

接受情况：logbands 的 100 个正例均过实验门限；bandflux 为 99 个。包络在部分场景给出错误候选，但因峰不唯一，没有被接受。40 个歧义 / 负例（同音反复 20 + 无关旋律 20）在全部四种方法下都未被接受；不能据此推导真实使用中的错误接受率为零。

初试的 50 个正例上，logbands / bandflux 均为 50/50，共享包络为 20/50，当前 robust 包络为 22/50；20 个歧义 / 负例同样全部被拒绝。这一批用于初步观察，结论主要列出后续复核结果。

## 验证与复现

## 下一步建议

1. 保留包络法作为对照和可能的局部细化手段，用 logbands 增加候选位移或复核候选。当前实验仍是固定整体偏移，不使用 DTW，也未做漂移校正。
2. 新增更多真实设备、单音 riff、重复乐句、长停顿和伴奏比例变化的素材；重复乐句比本次同音反复更复杂，尚未单独覆盖。
3. 为新特征单独校准分数、峰比和分段一致性，特别关注“高分却错一拍”的错误接受。
4. 验证低能量频带、混响、设备时钟偏差及窗口长度影响。64 ms 窗只是一组初始参数，不代表已完成参数优化。
5. 达到可接受的错误接受率后再决定接入；保留手动偏移与原始素材保护。
